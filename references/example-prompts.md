# Example Prompts

## 基本抓取

```text
請抓 TechNews 的 ai 分類第 1 到第 3 頁文章，輸出成 JSON。
```

## 先判斷分類再抓取

```text
請先取得 TechNews 目前可用分類，判斷「能源政策」最相關的分類，再抓最近 7 天文章並輸出摘要。
```

## 多分類抓取

```text
請抓 TechNews 的 能源科技 與 finance/金融政策 分類最近 7 天文章，輸出成 JSON。
```

## 抽象主題：能源政策

```text
請先取得 TechNews 目前可用分類，判斷「能源政策」最相關的分類，再抓最近 7 天文章並輸出摘要；先從最核心的 2 個分類開始，不夠再擴大。
```

## 抽象主題：美中科技戰

```text
請整理本周和美中科技戰相關的 TechNews 文章，先判斷要抓哪些分類，再輸出摘要與 JSON。
```

## 抽象主題：供應鏈風險

```text
請先查看 TechNews 可用分類，找出和供應鏈風險最相關的 3 個分類，抓最近 7 天文章，並列出最相關的標題。
```

## 讀取單篇文章

```text
請直接讀取這篇 TechNews 文章全文並整理成 JSON：https://technews.tw/...
```

## 先列表再補正文

```text
先抓 TechNews 的 ai 分類最近 7 天文章列表，挑出最重要的 3 篇後，再把那 3 篇全文抓出來。
```

## 從既有列表檔補抓正文

```text
我已經有一份 TechNews 列表 JSON，請直接用那份檔案補抓前 5 篇文章正文，不要重抓分類頁。
```

## 先篩關鍵字再補正文

```text
我已經有一份 TechNews 列表 JSON，請先挑出和 AI 電力相關的文章，按日期由新到舊排序後，只補抓前 3 篇正文。
```

## 只補指定連結

```text
我有一份選好的文章 URL 清單，請只對那些 TechNews 連結補抓正文，不要處理其他文章。
```

## 指定文章做成摘要圖卡

```text
我已經選好幾篇 TechNews 文章，請只對那些文章補抓正文，並用支援中文的字型輸出成一張 16:9 的 PNG 社群新聞圖卡。
```

## 既有清單直接輸出圖卡

```text
我已經有一份補好正文的 TechNews JSON，請幫我把前 3 篇合成一張社群新聞圖卡，輸出成 PNG。
```

## 匯出 CSV

```text
請抓 TechNews 的 semiconductor 分類最近 5 頁文章，並匯出成 CSV。
```

## 驗證 selector

```text
請先測試 TechNews ai 分類第 1 頁的 selector 是否還有效，再決定是否正式抓取。
```

## 只做小量驗證

```text
先抓 TechNews ai 分類第 1 頁，確認 title、date、content 都抓得到。
```
