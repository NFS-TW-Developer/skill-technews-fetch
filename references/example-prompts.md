# Example Prompts

## 基本抓取

```text
請抓 TechNews 的 ai 分類第 1 到第 3 頁文章，輸出成 JSON。
```

## 匯出 CSV

```text
請抓 TechNews 的 semiconductor 分類最近 5 頁文章，並匯出成 CSV。
```

## 驗證 selector

```text
請先測試 TechNews ai 分類第 1 頁的 selector 是否還有效，再決定是否正式抓取。
```

## 只做小量驗證

```text
先抓 TechNews ai 分類第 1 頁，確認 title、date、content 都抓得到。
```
